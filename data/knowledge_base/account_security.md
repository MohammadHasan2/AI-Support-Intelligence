# Account Security and Privacy Support

## Password problems
Customers who cannot sign in should use the official password-reset
process, if available.

Support must never ask customers to disclose their current password
or password-reset codes.

## Updating account details
Customers who need to update account information should use the
available account settings or contact support for guidance.

Support should verify the request through the approved process before
making changes to sensitive account information.

## Suspicious account activity
Customers who notice unfamiliar activity should contact support and
secure their account using the available official security procedures.

Support should investigate reported activity without claiming that
an account has been compromised unless the evidence supports that
conclusion.

## Personal information
Support should request only information necessary to investigate
the customer's issue.

Passwords, authentication codes, full payment-card details, and
banking credentials must not be requested in support conversations.

## Evidence and limitations
If the knowledge base does not document the required security procedure,
the assistant should acknowledge the limitation and direct the customer
to the appropriate support channel rather than inventing instructions.
