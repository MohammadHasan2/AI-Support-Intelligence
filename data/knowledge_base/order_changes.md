# Order Changes and Cancellation Support

## Requesting an order change
Customers who need to change an order should contact support as soon
as possible and provide their order number and requested change.

A change is not guaranteed until support confirms that it can be made.

## Address changes
Customers who entered an incorrect delivery address should contact
support promptly. Address changes may not be possible after an order
has been dispatched.

Customers should not assume that updating their account address
automatically changes an existing order.

## Item changes
Requests to change product quantities, remove items, or replace products
must be reviewed against the current order status and fulfillment progress.

Support should confirm any accepted change to the customer.

## Order cancellation
Customers requesting cancellation should provide their order number.
Cancellation eligibility depends on the current order status and the
applicable store cancellation policy.

If an order can no longer be cancelled, support should explain the
available options using the documented refund and return policies.
